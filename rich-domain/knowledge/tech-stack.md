# Technology Stack

## Backend
- .NET 10 LTS + C# 14, ASP.NET Core 10.
- Vertical Slice Architecture (Feature folders).
- EF Core + Npgsql (PostgreSQL).
- FluentValidation for input validation.
- Result<T> pattern for business errors.
- xUnit v3 for testing.

## Frontend
- Angular 21, TypeScript 5.9.x, Signals.
- PrimeNG components.
- Tailwind CSS v4.
- Auth: Active Directory (MSAL).

## Infrastructure
- PostgreSQL database.
- Active Directory for authentication.
- Local file storage (phase 1).
