# Technology Stack

## Backend
- .NET 10 LTS + C# 14, ASP.NET Core 10.
- Services with Dependency Injection (Direct DI).
- EF Core / Dapper.
- PostgreSQL / SQL Server.
- Microsoft.Extensions.Resilience (Polly v8).
- Local Development: Docker Compose setup.

## Frontend
- Angular 21, TypeScript 5.9.x, Signals + @ngrx/signals.
- pnpm package manager (strict-store, lockfile-only).
- Tailwind CSS / SCSS.
- Unit Testing: Vitest.
