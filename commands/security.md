description: Review security for all app
---
Review this .NET and Angular application for security issues.

Focus on:

- OWASP Top 10 (API + Web)

- Authentication & Authorization

- CSRF, XSS, SQL Injection, Command Injection, SSRF

- IDOR / Broken Access Control

- CORS, CSP, Cookies (HttpOnly, Secure, SameSite)

- JWT/Cookie security

- Input validation & output encoding

- File upload vulnerabilities

- Secrets, API keys, connection strings

- Sensitive data exposure & logging

- Dependency vulnerabilities

- Security headers

- Insecure cryptography

- Rate limiting and DoS protections

- Common .NET and Angular security best practices

For each finding include:

- Severity (Critical/High/Medium/Low)

- Why it's a risk

- File and line if possible

- Recommended fix

- Example code when helpful

Ignore style, formatting, and performance unless they create a security risk.
